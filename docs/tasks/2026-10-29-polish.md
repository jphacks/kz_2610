## 1. 地図の配色（優先度：高）

場所：`meshinowa/Views/GoogleMapCanvas.swift` の `makeUIView`（今は `map.mapStyle` で POI のラベルだけ消している）。

- マップの背景をクリームで塗ったり、半透明を重ねたりはしない。Google マップの配色（`GMSMapStyle`）を変える。
- スタイルの JSON は `MeshinowaTheme` の近くに定数として置く（例：`MeshinowaMapStyle.json`）。Google Cloud 側の設定は不要。
- 目標の色（モックの「直した後」）

| 対象 | 色 | 意図 |
|---|---|---|
| 陸地（`landscape`） | `#F6F1E6` | アプリのクリーム（`ground` #FDF8EE）に近づける |
| 建物の区画（`landscape.man_made`） | `#EFE8D8` | 陸地より少しだけ濃く |
| 一般道路（`road` / geometry） | `#FFFFFF` | 白 |
| 大通り・高速（`road.arterial` `road.highway` / geometry） | `#FBF6EC` | 黄色・オレンジをやめる |
| 道路の縁（geometry.stroke） | `#E6DDCB` | 細く目立たせない |
| 水（`water`） | `#C9DCE3` | 彩度を落とす |
| 公園・緑地（`poi.park` / geometry） | `#DDE6D3` | 彩度を落とす |
| 線路（`transit.line`） | `#B9C8C4` | 細く淡く |
| 地名・駅名などの文字 | `#7B7F7C`、縁取りは `#FDF8EE` | 補足の灰色 |

- 消すもの：Google のお店・公園・駅などのアイコン（`poi` の labels.icon と `transit.station` の labels.icon、`poi.business` 全体）。**地名・駅名・道路番号の文字は残す**（場所が分からなくならないように）。

- 完了の条件：地図の上で目立つのがアプリのピンだけ。緑のピンと Google の緑のアイコンが紛れない。保存の地図・マイマップ・友達のおすすめマップにも同じ配色が効く（`GoogleMapCanvas` を使っていれば自動）。

## 2. 記録のないお店のピンを見やすく（中）

場所：`meshinowa/DesignSystem/FoodGenreMark.swift`（輪郭の線）と `PlacePin`（`meshinowa/DesignSystem/RatingStamp.swift`）。

- ピンとして描く白いピン（`tone == .plain`）だけ、緑の線を 1.5 → 2.2 に太くし、影を少し強くする（目安：不透明度 0.22→0.35、半径 3→3.5）。
- 一覧・プロフィールの器（ピンでない所）の線は今のまま。`FoodGenreMark` に線の太さの引数を足し、`PlacePin` からだけ太くする。
- からし色・緑・ピンクのピンは変えない。

## 3. のれんの竿（中）

場所：`meshinowa/DesignSystem/NorenTabs.swift`（`style == .rod` の竿。今は `Capsule().fill(MeshinowaTheme.mustardInk)` の細い線）。

- 茶色の細い線をやめ、墨色（`MeshinowaTheme.ink` を少し明るくした #3B3530 相当。テーマに `rod` として色を足す）の太めの竿にする。目安：高さ 5pt、両端を丸く、下に軽い影。
- 竿の左右は、のれんの列より少し内側に収める（端から 2pt）。
- のれんの落ちて揺れる動きはそのまま。

## 4. 保存の「いいね／行きたい」の切り替え（低）

場所：`meshinowa/Views/SavedLibraryView.swift`（今は `NorenTabs(... style: .collection)`）。

- 2つだけの切り替えなので、のれんではなく軽い切り替えにする。白い面に細線、選択中はミント地（`MeshinowaTheme.mint`）にミントの文字（`mintInk`）。ハートと旗の印、件数は今どおり文字の前と後ろに。
- のれんはジャンル選びの部品として、地図だけに残す。
- **注意**：これは 10/28 に採用した案 2b（保存の2枚のれん）を戻す変更。ユーザーがこの見直しモックを見て依頼したもの。

## 5. プロフィールの「よく行くジャンル」（中）

場所：`meshinowa/DesignSystem/FoodGenreMark.swift` の `.faint`（不透明度 0.4）と、`meshinowa/Views/ProfileView.swift` のジャンル名の文字色。

- まだ行っていないジャンルの器を、不透明度 0.4 → 0.62 程度に。文字は `secondaryText`（#6B716D）にして、読める濃さにする。
- 行ったジャンル（からし色・太字・件数）はそのまま。
- `.faint` をほかの画面でも使っていれば、同じく読みやすくなることを確かめる。

## 6. タブバーの影（低）

場所：`meshinowa/Views/MainTabView.swift`（バーの影 `opacity 0.14, radius 10`、真ん中のボタンの影 `opacity 0.18, radius 4`）。

- バーの影を `opacity 0.07, radius 6, y 1` 程度、真ん中のボタンの影を `opacity 0.12, radius 3, y 1` 程度に弱める。
- 形・大きさ・はみ出し方・提灯の灯りは変えない。
- 地図の上でもバーが沈まないことを確かめる（地図はクリーム寄りになるので、白いバーが見えるか）。
