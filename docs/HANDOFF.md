## 仕組みのメモ

- **ジャンルの判定（`FoodGenre.infer`）**：Google の種類 → 店名の言葉（「バーガー」は「バー」より先に洋食）→ 地図のカテゴリ → その他。ジャンルを指定して検索したお店は `searchedFoodGenre` でそのジャンルとして扱う。
- **お店の照合**：`SavedRestaurant.identifier(for:)` は Google の ID があれば `google:…`、なければ店名＋座標。ID をそのまま比べず、`matches(_:)` / `isSameStore(as:)` を使うこと。
- **評価の流れ**：真ん中のボタン → `ReviewTargetPicker` → `QuickRatingSheet` → 必要なら `ReviewEditor`。保存は `LocalReviewStore.save`（送信待ちを `pending` に積む）→ `FriendStore.flushReviews`（Cloudflare）。
- **地図**：初期表示は「すべて」（一般のお店＋友達のお店、友達のお店を優先）。「友達」は友達が評価したお店だけ。ピンの優先順は 選択中 → 友達の評価あり → 自分の記録あり → 一般。
