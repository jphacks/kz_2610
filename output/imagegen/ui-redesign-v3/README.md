# メシノワ UIモック v3

ユーザー提供の2枚のUI参考画像を視覚参照として、built-in image_genで12画面を作成。白地・黒い文字・料理写真・下線タブ・緑の主要操作を共通原則とする画像モック。アプリ実装は変更していません。友達機能などは完成形の提案です。店舗・人物・レビューは架空です。画像生成により日付・地理・店舗の写真や属性には不一致があります。実装用の正確な仕様・店舗情報として扱わないでください。
