## デモ用サーバー

既存の接続先に新APIを反映するには、`0004_profiles_and_backup.sql`までのmigrationとWorker更新が必要です。
コードの変更だけでは既存サーバーは更新されません。本番の作成・デプロイ・実データ削除はこの実装作業では行いません。

ローカル確認はリポジトリのルートで実行します。

```sh
npm ci --prefix cloudflare
npm run db:local --prefix cloudflare
npm run dev --prefix cloudflare
```

iOSシミュレータは`Config/Cloudflare.xcconfig.local`のoriginをローカルWorkerに合わせて再ビルドします。実機からはHTTPSの開発用APIが必要です。

## 2台での通し確認

1. Aで名前・アイコン・自己紹介を保存。BがIDで申請し、Aが承認する。
2. Bの友達一覧からAのプロフィールを開き、編集内容が表示されることを確認。
3. Aが店舗をいいねし、レビューを投稿・編集。Bのフィード・地図・店舗詳細で同じ評価になることを確認。
4. Lensをお気に入り・選択した友達・0人に変更。地図と詳細の人数・平均が一致することを確認。
5. Aを圏外にし、レビューを編集・削除してアプリを再起動。通信を戻すと共有待ちが解消し、Bでも削除されることを確認。
6. AがID検索をオフ。未接続のCから見つからず、Bの既存の友達関係は維持されることを確認。
7. BがAをブロック。プロフィール・評価が互いに非表示になり、解除しても友達へ自動復帰しないことを確認。
8. Aで写真・来店日付きの記録をバックアップし、コードを発行。別端末で引き継ぎ、写真・保存・プロフィール・友達が復元されることを確認。
9. 実ユーザーではなく不要なテストアカウントで削除を確認。以前の認証情報と引き継ぎコードが使えないことを確認。
