## デザインの決まり

デザインの元は `output/wa-design/` の HTML（ブラウザで開くと動きも見られる）。

| ファイル | 内容 |
|---|---|
| `category-pins.html` | ジャンル別ピンの形・状態（採用） |
| `tabbar-noren.html` | タブバー（案2「提灯の灯り」を採用） |
| `screens.html` | 保存・友達・プロフィール |
| `review-editor.html` | 評価の画面 |
| `fixes.html` | 取り込み後の見直し（地図の上は A 案を採用） |
| `index.html` / `tabbar.html` | 初期の検討（不採用を含む） |

1. **見た目はモダン、和は「選んだ瞬間」だけ。** カテゴリののれん、押すと灯るタブバーの提灯、記録すると押される判子。ふだんの画面に和柄・和のモチーフを足さない。
2. **形＝ジャンル、色＝記録の意味。** ピンと一覧の器の形はジャンル（`FoodGenre` / `FoodGenreMark`）。
   - 緑：主ボタン、友達の評価、行きたい
   - からし色：自分の評価だけ
   - ピンク：いいねだけ
   - 白に緑の線：記録なし
3. **のれん（`NorenTabs`）の部品と動きは変えない。** 項目は `RestaurantGenre` に足せば並ぶ。
4. **タブバーは文字なしのアイコンだけ。** 真ん中の評価ボタンはバーより少し大きく、上下に少しはみ出す。
5. **空の状態は同じ形**：ミントの丸の中のアイコン（お椀など）＋見出し＋緑の主ボタン＋白い副ボタン。

## 仕組みのメモ

- **ジャンルの判定（`FoodGenre.infer`）**：Google の種類 → 店名の言葉（「バーガー」は「バー」より先に洋食）→ 地図のカテゴリ → その他。ジャンルを指定して検索したお店は `searchedFoodGenre` でそのジャンルとして扱う。
- **お店の照合**：`SavedRestaurant.identifier(for:)` は Google の ID があれば `google:…`、なければ店名＋座標。ID をそのまま比べず、`matches(_:)` / `isSameStore(as:)` を使うこと。
- **評価の流れ**：真ん中のボタン → `ReviewTargetPicker` → `QuickRatingSheet` → 必要なら `ReviewEditor`。保存は `LocalReviewStore.save`（送信待ちを `pending` に積む）→ `FriendStore.flushReviews`（Cloudflare）。
- **地図**：初期表示は「すべて」（一般のお店＋友達のお店、友達のお店を優先）。「友達」は友達が評価したお店だけ。ピンの優先順は 選択中 → 友達の評価あり → 自分の記録あり → 一般。
