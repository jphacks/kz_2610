# 金沢工大・友達の評価だけをモックにした発表版

ブランチ：`codex/kit-presentation-demo`

## 起動

Xcodeで `meshinowa.xcodeproj` を開き、Schemeを **meshinowa-Presentation**、実行先を **iPhone 17 Pro** にしてRunする。ホーム画面のアプリ名は **meshinowa デモ**。歓迎画面を省略し、金沢工業大学・扇が丘キャンパス周辺の地図を開く。

```bash
xcodebuild -project meshinowa.xcodeproj -scheme meshinowa-Presentation -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```

発表版のBundle IDは `jp.meshinowa.app.presentation`。通常版 `jp.meshinowa.app` と同時にインストールでき、保存データも分かれる。通常版は **meshinowa** Schemeで起動する。

## 本物のデータとモックの範囲

| 内容 | データの扱い |
|---|---|
| 地図、店舗検索、検索結果 | 通常版と同じGoogle Maps / Google Placesを使う |
| 店舗名、住所、緯度・経度、Place ID、店舗種別 | Googleの検索結果をそのまま使う。仮の座標は使わない |
| 店舗写真、写真の提供者表示 | 通常版と同じGoogle Placesの取得処理を使う。取得できないときは既存の写真なし表示 |
| 友達、友達の星評価とコメント | 発表用のモック。友達6人、全対象店舗を取得できればレビュー12件 |
| 自分のレビュー・いいね | 自動生成しない。自分で行った操作だけを保存する |

発表開始時にGoogleから次のお店を検索し、名前・金沢工大からの距離・Place IDを確認できた店舗にだけ、友達のモックレビューを結び付ける。

- カレーのチャンピオン 野々市本店
- 鬍鬚張魯肉飯 金沢工大前店
- 8番らーめん 金沢工大前店
- レストラン ラ・テラ（金沢工業大学）
- ミスタードーナツ 野々市ショップ

この一覧は友達の評価を付ける対象であり、一般の検索結果をこの5店舗に制限するものではない。「すべて」には、Googleから取得したほかのお店も表示する。地図上の名前や位置は取得結果に従う。

取得できない対象のお店と、そのお店へのモックレビューは表示しない。一部取得に失敗した場合は友達画面に案内を出し、下に引いて再読み込みできる。Googleの検索結果の代わりに以前の固定カタログや座標を返す処理はない。

## 発表の流れ

1. 地図で周辺のお店を探す。検索欄・「このエリアで探す」は実際のGoogle検索として動く。
2. 「友達の評価」に切り替え、Googleの実店舗に付いた架空の友達の点数とコメントを見せる。
3. 店舗カード・詳細で、実際の店舗情報と写真、友達の声を確認する。
4. 友達タブでフィードやおすすめマップを開き、Friend Lensで誰の評価を使うか切り替える。
5. 中央の評価ボタンから自分のレビューを入力する。保存・プロフィールには、実際に操作した記録だけが増える。

上部の **友達を戻す** は、友達のお気に入り・解除などをモックの初期状態に戻す。自分のレビューやいいねは削除しない。

## 以前の発表版からの更新

前の版が自動作成した「発表用サンプル：友達とまた行きたいお店。」というレビューと、3軒の初期いいねは、アップデート後の初回起動で削除する。それ以外のレビュー・いいねは保持する。新しく自分のサンプルを作る処理はない。

## 通信と通常版との分離

- 発表時はGoogle MapsとGoogle Placesに接続できる通信環境が必要。
- Google Maps / PlacesキーのiOSアプリ制限を使っている場合は、発表版のBundle ID `jp.meshinowa.app.presentation` を許可対象に追加する。実機ではXcodeのSigningで自分のTeamも選ぶ。
- 友達のモックはCloudflareへ送信しない。発表版のFriendStoreは、Cloudflareが設定済みでもゲストアカウントを作らず、自分の記録も端末内にだけ保存する。
- Googleの店舗オブジェクトは実行中のメモリで保持し、写真には既存の取得・表示・提供者表記の処理を使う。
- 通常のDebug／Releaseでは、対象店舗の検索語・架空の友達・レビュー定義をコンパイルしない。
- このブランチをmainへマージ・pushする操作は行っていない。
