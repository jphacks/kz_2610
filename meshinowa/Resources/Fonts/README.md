# 同梱フォント

デザイン資料で指定された書体を、改変せず同梱しています。

- Zen Maru Gothic: Medium / Bold / Black
  - https://github.com/google/fonts/tree/main/ofl/zenmarugothic
  - ライセンス原文: `zenmarugothic/ZenMaruGothic-OFL.txt`
- M PLUS Rounded 1c: Bold / ExtraBold / Black
  - https://github.com/google/fonts/tree/main/ofl/mplusrounded1c
  - ライセンス原文: `mplusrounded1c/MPLUSRounded1c-OFL.txt`

どちらもSIL Open Font License 1.1。各フォルダの著作権表示・ライセンスを保持します。
`Info.plist` の `UIAppFonts` で登録し、`MeshinowaFont` でDynamic Typeに対応させています。

M PLUS Rounded 1cは配布フォルダにライセンスファイルがないため、TTF内の著作権表示・OFL 1.1の指定を確認し、共通のOFL 1.1全文と合わせて同梱しています。
