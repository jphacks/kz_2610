MESHINOWA · DESIGN PROPOSAL

見た目は和、使い心地はモダン。

UI（色・文字・形・柄）は和の食事処の見立てでまとめ、UX（操作・動き・情報の出し方）は今どきの iOS アプリの作法に揃える「和モダン」案です。アプリの動きと画面構成は今のまま変えません。

コンセプト：UIは和、UXはモダン

地図は「城下町の絵図」、お店は「軒先の提灯」、カテゴリは「のれん」、お店の情報は「お品書き」、自分の評価は「判子」。和柄やモチーフは要所だけに使い、文字が読みやすいことを優先します。

UI ＝ 和見た目で和を感じさせる
  • 和紙の生成り色を地にし、墨色の文字と罫線を使う
  • 見出しと店名は明朝体にする
  • 色は和色（常磐・朱・山吹・漆）
  • のれん・提灯・お品書き・判子などのモチーフ
  • 青海波・組子を区切りに少しだけ使う
UX ＝ モダン使い心地は iOS 標準のまま
  • シート・スワイプ・戻る操作は iOS 標準の動き
  • 数字・日付・件数は算用数字で、すぐ読める
  • 短く軽いスプリングの動きと触覚フィードバック
  • タップできる範囲は 44pt 以上、状態は色＋アイコン＋文字で示す
  • 視差効果を減らす設定・Dynamic Type・VoiceOver に対応
一、和紙と墨真っ白をやめて生成りの和紙色を地にし、文字と罫線は墨色にします。影はぼかさず、ずらした墨の影で版画のような手触りを出します。
二、見出しは明朝店名・画面タイトル・数字は明朝体に変えます。本文と操作の文字は読みやすいゴシックのままにします。
三、色は意味で使い分ける常磐色＝操作、朱＝いいね、山吹＝自分の評価。今の「緑・ピンク・マスタード」の役割をそのまま和色に移します。
四、柄は控えめに青海波・組子・点線の罫は、区切りや空の画面にだけ使います。地図とお店の上には柄を敷きません。

UX：モダンにするところ

見た目を和にしても、使い方で迷わせないようにします。多くは今のアプリがすでにできていることなので、和の見た目にしても崩さないことが目的です。

標準の操作を崩さないシートの段階表示（中・大）、端からのスワイプで戻る、下に引いて閉じる。和の枠をかぶせても、つまみ（グラバー）と閉じるボタンは残します。
動きは短く、軽くのれんが垂れる・提灯が灯る動きは 0.25〜0.35 秒のスプリングにします。視差効果を減らす設定ではフェードだけにします（のれんは対応済み）。今あり
触覚フィードバックのれんの切り替え・いいね・評価の確定で軽く振動させます。判子を押す瞬間に「ぽん」と触覚を返すと、和の見た目とモダンな手触りがつながります。
数字はすぐ読める形で点数・件数・日付は算用数字にします。漢数字や縦書きは、読み取らせる場所には使いません。
色だけに頼らないいいね＝朱＋ハート、自分の評価＝山吹＋数字、選択中＝大きさ＋灯り。色の区別がつきにくい人にも同じ情報が伝わるようにします。
カードは横にスワイプお品書きカードは、ぴたっと止まる横スクロールにし、隣のカードを少しのぞかせて位置の点も付けます。ピンとカードは今の連動のままです。今あり
待ち時間の見せ方検索中は和紙色のスケルトンを薄く光らせます。結果の通知は、上に短く出して数秒で消すトーストにします。
文字の大きさに追従明朝の見出しも relativeTo: で Dynamic Type に追従させます。大きい文字では柄や飾りを省きます。今あり

部品ごとの見立て

差し替えるのは見た目だけです。どのファイルの何を変えるかの目安も付けています。

今の部品UI（和）UX（モダン）変えるところ
カテゴリのタブのれん（据え置き）。上に木の竿を一本足し、選ばれた布の中央に家紋風の丸を入れる押したらすぐ切り替え、揺れは後から。4つまでは等分し、それより多ければ横スクロールNorenTabs.swift の cloth
地図のピン提灯。ふだんは和紙色、いいねは朱、自分の評価は山吹で点数入り、選択中は大きく灯る見た目が小さくても、タップできる範囲は 44pt。重なるピンは間引く（今のまま）PlacePin（MapHomeView）・ScorePin
地図のスタイル今の muted を据え置く。上に生成りの半透明を重ねて、紙の絵図の色味に寄せる（任意）地図の操作・拡大縮小は標準のままMapHomeView の overlay
「このエリアで探す」木札。四角い札に墨の縁、朱の点必要なときだけ出し、検索中はくるくる表示PaperButtonStyle に札のスタイルを追加
下のお店カードお品書き。和紙地に墨の細枠、ずらした影。写真枠は角皿横スワイプで切り替え、ピンと連動。タップで詳細をシートで開くPaperCard・RestaurantPreview
浮いたタブバー漆の盆。漆黒に金の細い縁。選択中は朱の丸に白い印、文字は金アイコンは SF Symbols のまま。押すと触覚FloatingTabBar（MainTabView）
画面タイトル明朝の大見出しと、下の二重罫スクロールすると小さな見出しに縮むMeshinowaFont.heading
下線タブ（いいね／行った）筆で払ったような下線下線が横にすべって移るSavedLibraryView
並び替えのチップ千社札。角ばった札で、選択中は墨地に白抜き横スクロール。選択中はチェックも付けるRestaurantCollectionControls
自分の評価判子。朱の角印に明朝の数字、少し傾ける数字はまっすぐ読める向き。評価を確定すると押印の動きと触覚RatingStamp
件数・数字明朝体の算用数字算用数字MeshinowaFont.number
空の画面空のお椀の線画次にする操作のボタンを必ず置くSavedLibraryView ほか
区切り点線の罫と組子の帯。詳細の上部だけ青海波新しい WaPattern 部品

※ コントラストは、墨と生成りで約 13:1、朱の地に白抜きの文字で約 4.6:1。今と同じ水準を保てます。

色の別案

骨組みは同じままで、主の色を差し替えた案です。

甲：常磐（本案）

今のブランドの緑と、アイコンの「お椀の輪」をそのまま活かせる。いちばん移行しやすい案です。

乙：藍染

のれん・主操作を藍色にする。より「食事処」らしくなるが、アイコンの緑と揃わなくなります。

丙：夜の横丁

地図以外の画面を漆黒の地にし、提灯の灯りを主役にする。ダークモード対応の下敷きにもなります。
