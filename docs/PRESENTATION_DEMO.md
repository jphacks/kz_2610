# 金沢工大・発表用デモ

ブランチ：`codex/kit-presentation-demo`（`main` の `5ff216b` から作成）

## 起動

1. Xcodeで `meshinowa.xcodeproj` を開く。
2. Schemeを **meshinowa-Presentation**、実行先を **iPhone 17 Pro** にしてRun。
3. ホーム画面のアプリ名は **meshinowa デモ**。歓迎画面を省略して金沢工業大学・扇が丘キャンパス周辺の地図を開く。

コマンドでビルドする場合：

```bash
xcodebuild -project meshinowa.xcodeproj -scheme meshinowa-Presentation -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```

通常版のSchemeは従来どおり **meshinowa**。発表版のBundle IDは `jp.meshinowa.app.presentation` で、通常版 `jp.meshinowa.app` と並べてインストールできる。保存・レビュー・設定も別のアプリ領域に入る。

## 発表の流れ（約2分）

1. **地図**：「この大学の近くで、今日はどこに食べに行く？」。「すべて」には一般のお店と友達のおすすめを一緒に表示する。
2. **友達の評価**へ切り替え：「知らない人全員の平均ではなく、自分の友達が行ったお店から選べる」。
3. **チャンピオンカレー**のピン・カード・詳細を開く。友達3人の平均約4.7点とコメントを見せる。
4. **友達タブ → おすすめを地図で見る → Friend Lens**。「お気に入りの友達」に切り替えると、2人が評価した3軒に点数の対象が変わることを見せる（それ以外のピンは未評価表示）。
5. **保存／プロフィール**で自分の記録を見せる。中央の評価ボタンから未評価のお店を選び、星を付ける操作もできる。
6. 繰り返し練習するときは上部の **初期化** を押す。確認後、この発表版の自分の記録・いいね・友達のお気に入りや解除を初期状態へ戻す。

友達のデータとお気に入りの変更はメモリ内だけで、アプリ再起動でも初期状態に戻る。自分のレビュー・いいねは発表版の端末内に残るので、練習の前には「初期化」を使う。

## 通信と通常版への分離

- 地図の背景表示には既存のGoogle Mapsキーと通信環境が必要。店舗一覧の検索・友達の評価・保存・レビューは固定データで動く。
- 実機で使う場合はXcodeのSigningで自分のTeamを選ぶ。Google MapsキーのiOSアプリ制限を使っている場合は、発表版のBundle ID `jp.meshinowa.app.presentation` も許可対象に追加する。
- 発表版のFriendStoreは、Cloudflareの設定が入っていてもバックエンドを使わず、ゲストアカウントを作らず、評価を外部送信しない。
- `Presentation` 構成だけに `PRESENTATION_DEMO` を設定する。通常のDebug／Releaseでは、実店舗カタログ・架空の友達・レビューの定義をコンパイルしない。
- 初期化の対象は発表版のアプリ内データだけ。通常版の記録には触れない。
- mainへのマージ・pushは、この依頼では行わない。
