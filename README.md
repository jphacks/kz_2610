# meshinowa（メシノワ）

おいしい店は、友達が知っている。

友達のおすすめを地図から探す、iPhone向けアプリです。
iOS 17以上・SwiftUI・MapKit・Supabaseを使って、少しずつ開発します。

## 開発環境

- Xcode（iOS 17以上のSDK）
- iOSシミュレータ
- XcodeGen（プロジェクト構成を変更する場合のみ）

## 起動方法

1. `meshinowa.xcodeproj` をXcodeで開く。
2. `meshinowa` スキームとiPhoneシミュレータを選ぶ。
3. Runで起動する。

実機で動かす場合は、XcodeのSigning & Capabilitiesで自分のTeamを設定してください。
Bundle Identifierは仮の値です。

プロジェクト構成は `project.yml` で管理しています。
構成を変更したら、XcodeGenが入った環境で `xcodegen generate` を実行し、
生成されたプロジェクトも一緒にコミットしてください。

保存処理のテストは、XcodeでiPhoneシミュレータを選び、Product → Test（⌘U）で実行できます。
テストは一時フォルダを使い、通常の保存一覧には書き込みません。

## 現在の状態

歓迎画面と「紙の地図」テーマの共通色・カード・評価スタンプを用意しています。
評価スタンプの評価あり／未評価は、XcodeのSwiftUI Previewで確認できます。
アプリアイコンと歓迎画面には、Claude Designの提供デザイン4c「お椀の輪」を使用しています。
アイコンは元SVGの図形・色から書き出した1024pxのPNGです。
ホーム画面用PNGには角丸を付けず、歓迎画面の角丸はSwiftUIで付けています。
UIはZen Maru Gothic、数字とワードマークはM PLUS Rounded 1cを使用しています。
フォントはアプリに同梱し、Dynamic Typeに対応する共通定義から利用します。
出典とライセンスは `meshinowa/Resources/Fonts/README.md` を参照してください。
歓迎画面は共通部品を確認する初期実装で、最終デザインの再現はこれからです。
共通の主・副ボタンと、地図ホームの初期実装を追加しています。
歓迎画面の「マップを開く」から地図に進めます。
初期表示は東京駅周辺で、現在地の取得は行いません。
地図を移動し、店名・ジャンルまたは「このエリアの飲食店を検索」でMapKit検索を試せます。
検索には通信が必要です。マーカー選択で店舗プレビューを表示します。
検索後は「一覧」で同じ検索結果を見られ、一覧から地図上のお店を選択したり保存したりできます。
ジャンルは「すべて／飲食店／カフェ／ベーカリー」から選択できます。
選択すると取得済みの候補を地図・一覧で同じ条件に絞り込みます。
さらに「このエリアの…を検索」で、そのジャンルを指定して新しく検索できます。
分類はMapKitの店舗カテゴリを使用し、カテゴリ不明のお店は「すべて」にだけ表示します。
「詳細」で住所などを確認でき、「経路を見る」でAppleマップの徒歩経路を開きます。
営業時間や価格など、取得していない情報は推測しません。
店舗プレビュー・詳細で「行きたい」の保存と解除ができ、地図右上の「保存」から一覧を開けます。
保存情報は端末のApplication Support内のJSONに保存し、アプリを再起動しても保持します。
書き込み失敗時は保存表示を変更せず、読み込み失敗時は既存データの上書きを防ぎます。
店舗の照合には店名と丸めた座標を使用するため、店舗名変更・移転などの照合は今後の課題です。
アカウント間・端末間の同期はなく、アプリ削除で端末内の保存情報も消えます。
友達の評価連携・フィルター・認証はこれから実装します。

## 友達の評価デモ

実店舗の詳細から、自分のレビューを端末内に投稿・編集・削除できます。
評価は1〜5の0.5刻み、コメントは任意で300文字まで。同じ店舗のレビューは更新されます。
この段階では外部送信や友達への公開は行いません。

歓迎画面の「架空データで友達の評価を試す」から、架空店舗5件・架空の友達8人の地図を開けます。
評価マーカー・店舗プレビュー・詳細で、平均・人数・ひとことを確認できます。
集計は1人1店の最新評価だけを数え、未評価は平均なしとして扱います。
デモは実店舗検索・端末の保存一覧・外部サービスと接続せず、経路案内も行いません。
Friend Lensは「友達全員／お気に入りの友達／選択した友達」に対応しています。
選択画面で「人数の評価で表示」を押すと、地図・プレビュー・詳細が同じ対象で再集計されます。
キャンセル時は変更を適用しません。対象0人や未評価のお店には0点を付けません。
デモのお気に入りは固定の3人で、Lensの選択はデモ画面を開いている間だけ保持します。
